# Naveen Siddhantham, portfolio

React + Vite. All content is in `src/data.js`. Fonts (Bricolage Grotesque, Source Sans 3) are bundled, so no internet font loading is needed.

## Run locally
    npm install
    npm run dev

## Add your photo
Save it as `public/photo.jpg` (portrait, roughly 4:5). Until then the page shows your initials.

## Deploy
Push to GitHub, import the repo on Vercel or Netlify. Build command `npm run build`, output folder `dist`.
